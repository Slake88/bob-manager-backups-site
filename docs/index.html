BOB Manager Backups é a aplicação destinada a apoiar cópias de segurança internas do BOB Manager para o Google Drive, exclusivamente no contexto dos Blue On Black.

02 / ESTADO

Pré-verificação não é backup.

No código consultado existe um script de pré-verificação da ligação ao Google Drive. O script verifica a autorização, consulta metadados de uma pasta própria e cria uma pasta vazia se não a encontrar.

Esse script não transfere conteúdos de ficheiros nem executa cópias de segurança. Não foram validados operacionalmente backups automáticos, cifragem, retenção ou recuperação.

Este site apenas apresenta informação. Não disponibiliza autenticação, carregamento ou descarga de backups.

03 / AUTORIZAÇÃO GOOGLE

Acesso limitado por ficheiro.

O âmbito previsto no código de pré-verificação é drive.file. Segundo a documentação da Google Drive API, este âmbito permite criar ficheiros e aceder aos ficheiros que a aplicação criou ou que o utilizador abriu ou partilhou com ela. Pode permitir consultar, alterar e eliminar esses ficheiros; não concede acesso geral a todo o Google Drive.

A autorização Google é distinta da autenticação e das permissões internas do BOB Manager. O âmbito efetivamente concedido e a ausência de âmbitos adicionais ainda têm de ser confirmados.
